КАРЩИКИ — ЦЕХА

Статическая мини-игра для GitHub Pages. Онлайн-база и сервер не нужны.

Установка:
1. Распакуйте архив.
2. Загрузите ВСЁ содержимое папки на GitHub Pages (в корень репозитория либо в папку, настроенную для Pages).
3. Откройте опубликованный адрес в Safari на iPhone.
4. Нажмите «Поделиться» → «На экран Домой».

Псевдоним, аватар, звук и личный счёт сохраняются локально в браузере на устройстве.
Очки — только игровой результат: без ставок, покупок, переводов и обмена на деньги.
