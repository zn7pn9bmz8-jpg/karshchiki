КАРЩИКИ — ЦЕХА · ВЕРСИЯ 3

Загрузка на GitHub Pages:
1. Распакуйте архив.
2. Откройте папку karshiki_cehi внутри архива.
3. Загрузите ВСЁ её содержимое в корень репозитория GitHub (index.html должен лежать в корне).
4. В настройках репозитория откройте Settings → Pages и выберите нужную ветку и папку /root.
5. Откройте опубликованный адрес в Safari на iPhone.
6. Нажмите «Поделиться» → «На экран Домой».

В папке icons уже лежат icon-192.png и icon-512.png. Пустой файл для GitHub не нужен: папка содержит реальные иконки приложения.

Псевдоним, аватар, звук и личный игровой счёт сохраняются локально в браузере на устройстве. Сервер и онлайн-база не используются.
